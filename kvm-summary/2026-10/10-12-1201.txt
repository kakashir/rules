static const char *device_path;
static const char *sysfs_path;
static atomic_int stop;

static void *open_close(void *unused)
{
	(void)unused;

	while (!atomic_load(&stop)) {
		int fd;

		if (access(sysfs_path, F_OK))
			continue;
		fd = open(device_path, O_RDWR);
		if (fd >= 0)
			close(fd);
	}
	return NULL;
}

int main(int argc, char **argv)
{
	pthread_t threads[THREADS];
	int i;

	if (argc != 3)
		return 1;
	device_path = argv[1];
	sysfs_path = argv[2];

	for (i = 0; i < THREADS; i++)
		if (pthread_create(&threads[i], NULL, open_close, NULL))
			return 1;

	sleep(45);
	atomic_store(&stop, 1);
	for (i = 0; i < THREADS; i++)
		pthread_join(threads[i], NULL);
	return 0;
}

New:  PCI: Add pci_find_free_ext_cap_offset() helper
[PATCH v2 1/7] PCI: Add pci_find_free_ext_cap_offset() helper
Author: Jose Ignacio Tornos Martinez <jtornosm@redhat.com>

Add helper function to find free space in PCI extended configuration
space. This is needed by VFIO variant drivers that need to use unused
extended config space for device-specific purposes, such as passing
metadata to VMs.

The function walks the extended capability chain (with TTL to prevent
infinite loops on malformed chains), then scans for a contiguous region
of zeroed space of at least the requested size. This avoids hardcoding
capability sizes and correctly handles capabilities of any length.

Use case: The qcom-vfio-pci variant driver uses this to find space for
caching host MSI addresses that need to be passed to Qualcomm device
firmware in VMs.

Signed-off-by: Jose Ignacio Tornos Martinez <jtornosm@redhat.com>

New:  KVM: arm64: Reject the GICv5 CPU interface hypercalls under pKVM
[PATCH v2 1/5] KVM: arm64: Reject the GICv5 CPU interface hypercalls under pKVM
Author: Fuad Tabba <fuad.tabba@linux.dev>

__vgic_v5_save_apr() and __vgic_v5_restore_vmcr_apr() remain callable
once pKVM has finalised. pKVM never registers a GICv5 vgic, so neither
has a valid caller in protected mode, and on a GICv3 machine both reach
a register that is UNDEFINED at EL2 and panic the hypervisor.

Move both into the band the dispatcher rejects once pKVM has finalised.

Fixes: af325e87af5da ("KVM: arm64: gic-v5: Add vgic-v5 save/restore hyp interface")
Signed-off-by: Fuad Tabba <fuad.tabba@linux.dev>
